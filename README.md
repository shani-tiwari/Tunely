# Tunely — Your Ultimate Web Shows & Movies Info Platform 🎬🍿

Welcome to **ShowHub**, a slick and modern frontend project that brings you the latest released web shows, series, movies, trailers, actor details, and where to watch or rent them — all in a beautifully responsive and optimized app.

***

## Project Journey 🚀

This project was all about crafting an engaging frontend that connects to live APIs to fetch rich entertainment data on demand. I designed multiple pages for **Popular**, **Trending**, and **People** sections to make browsing fun and intuitive.

The biggest focus was on smooth user experience with powerful **search and filtering** capabilities across vast media data. Performance optimization and responsive design were top priorities, ensuring the app runs lightning-fast and looks great on any device.

***

## Tech Stack 🛠️

- **Frontend:** React, React Router, Axios for API calls, React Context for state management  
- **Features:** Dynamic multi-page navigation, search and filter components, lazy loading for images and data, React.memo and Suspense for speed  
- **Design:** Tailwind CSS with mobile-first responsive layouts, optimized media loading with Intersection Observer

***

## Features & Highlights 🔍

- Fetches and displays comprehensive info on web shows, movies, trailers, and actors  
- Dedicated pages for **Popular**, **Trending**, and **People** categories  
- Global search bar with instant filtering by genre, year, rating, and more  
- Smooth, fast-loading UI with lazy loading and memoized UI components  
- Fully responsive and accessible on desktops, tablets, and phones

***

## Learnings 📚

Building ShowHub sharpened my skills in API integration, asynchronous React data flows, advanced component optimization, and responsive UI/UX design. Managing complex state and ensuring smooth interactions under large datasets was a rewarding challenge as well.
